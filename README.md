# 物化生工业科普小游戏

十三个方向的科普小游戏（物理 / 化学 / 生物 / 数学 / 工程），每个都借了市面上好玩游戏的壳。全部**单文件、零依赖**，双击即玩。每通关一个游戏，解锁它的 3 条史实故事。

**https://01dingzu.github.io/science-games/**

## 目录结构

```
index.html          聚合页（卡片 + 通关进度 + 史实图鉴入口）
hub.js              共享模块：返回聚合页按钮 + 统一结算面板 + 通关打点
stories.js          史实故事库（39 条）+ 结算史实卡 + 解锁记录
lore.html           史实图鉴（按五大学科分栏，未解锁显示来源游戏）
1-fusion.html       游戏页，命名规则 <序号>-<slug>.html
...
tools/              开发用验证脚本，不参与网页运行
```

## 关卡设计原则

所有游戏都是多关卡制，遵循从 Baba Is You / Celeste / Monument Valley / Snakebird 归纳的**锯齿难度曲线**：

1. **一关只教一个新机制**，首关几乎不可能输
2. 难度靠**变化**不靠堆数值（加规则，而不是把敌人从 3 个加到 30 个）
3. **峰值后必接回落关**（喘息关 / 变体关），给爽感和消化时间
4. **终局关 = 综合考**，前面所有机制一起上

各游戏关卡表写在文件顶部的 `LEVELS` / `STAGES` / `ORDERS` / `CHAPTERS`，难度值写在同一文件的 `DIFF` 数组里，页面底部会渲染成难度条。

## 史实故事系统

39 条故事（13 个游戏 × 3 条）集中在 `stories.js`，每条带学科标签和可信度标注（`史实` / `传说`）。

设计上遵守五条：

1. **认知挂钩** —— 故事讲的是「你刚才做的那件事」的来历，不是随机科普
2. **只在停机时刻** —— 通关结算面板里出现，绝不在关卡进行中弹窗打断操作
3. **一条一个反转** —— 带数字对比或意外（8 吨矿 → 0.1 克镭；64 km/h 的风吹塌一座大桥）
4. **标注可信度** —— 史实与传说分开标，传说反而更抓人
5. **与通关解耦** —— 可跳过、可回看、不影响得分

通关一个游戏即解锁它的 3 条：`lore.html` 按物理 / 数学 / 化学 / 生物 / 工程分栏展示，未解锁的显示「通关《XX》后解锁」。聚合页顶部有「史实图鉴 N/39」入口。

故事里的数字都逐条查证过。几处容易讲错的地方：恒星核合成的终点是**镍-56**（随后衰变为铁-56），不是铁-56；卡特事件用 CDC 口径（204 例、11 死）；工程师铁戒指「用魁北克桥废钢打造」是**未证实的说法**；埃拉托斯特尼的误差取决于「斯塔德」单位，不能说死。

## 怎么加一个新游戏

1. 复制一个现有游戏页，改名 `<序号>-<slug>.html`
2. 在 `<head>` 依次引入 `<script src="hub.js">` 和 `<script src="stories.js">`（顺序不能反）
3. 胜利处调 `hub.finish({ win:true, title, text, stat })`，失败 / 超时处调 `win:false`（`canContinue:true` 可给「继续玩」按钮）
4. 在 `stories.js` 里以游戏 id 为键加 3 条故事 `{ t, s, tag, ok }`；在 `lore.html` 的 `NAME` 表里加一行游戏中文名
5. 在 `index.html` 的 `.grid` 里加一张卡片：
   ```html
   <a class="card" href="11-xxx.html">
     <div class="ico">🎯</div><h2>游戏名</h2><p>一句话介绍</p>
     <span class="tag t-phy">物理 · 知识点</span><span class="done">✓ 已通关</span>
     <div class="ref">对标：某某游戏</div>
   </a>
   ```
   卡片的 `href` 就是通关记录的 id，进度条 `已通关 N/总数` 会自动跟着卡片数走，不用改 JS
6. 跑一遍 `node tools/smoke-cdp.mjs` 确认能玩 —— 里面的「接线检查」会拦截漏引 `hub.js` / `stories.js` / `hub.finish` / `DIFF` 的新页面

## 验证脚本

需要 Node 18+，在系统已有的 Edge / Chrome 上跑无头 CDP，零 npm 依赖：

```bash
node tools/smoke-cdp.mjs     # 10 个游戏能不能玩（发射 / 点击 / 推进一回合）
node tools/levels-check.mjs  # 关卡表健全性 + 光的迷宫逐关设计解可通 + 难度梯度单调
node tools/verify-hub.mjs    # 通关面板弹出 + 返回聚合页 + 徽章 + 清除记录
```

报告分别落在 `smoke-report-latest.txt`、`levels-check-report.txt`、`hub-verify-report.txt`。当前状态：**16/16、13/13、11/11 全通过**。

`smoke-cdp.mjs` 里有一项静态「接线检查」：遍历 13 个游戏页，缺 `hub.js` / `stories.js` / `hub.finish` / `DIFF` 任何一个就报警 —— 加新游戏时最容易漏的就是这四样。
